# Credit Card Fraud Detection — ML Web App

A Streamlit web application that predicts whether a credit card transaction is fraudulent using a machine-learning pipeline trained on the **Credit Card Fraud 2026** dataset (20,000 transactions, 25 features).

---

## 🗂️ Project Structure

```
project/
├── app.py               # Streamlit web application
├── train_model.py       # Model training script
├── requirements.txt     # Python dependencies
├── README.md
├── agent_instructions.md
├── .env.example
├── data/
│   └── dataset.csv      # Raw dataset (20 000 rows × 26 cols)
└── models/
    └── model.pkl        # Trained pipeline (generated by train_model.py)
```

---

## ⚙️ Local Setup & Run

### 1. Clone the repository
```bash
git clone https://github.com/<your-username>/<your-repo>.git
cd <your-repo>
```

### 2. Create & activate a virtual environment *(recommended)*
```bash
python -m venv venv
# Windows
venv\Scripts\activate
# macOS / Linux
source venv/bin/activate
```

### 3. Install dependencies
```bash
pip install -r requirements.txt
```

### 4. Train the model
```bash
python train_model.py
```
This will:
- Load `data/dataset.csv`
- Compare Logistic Regression, Random Forest, and Gradient Boosting
- Select the best model by cross-validated ROC-AUC
- Save the trained pipeline to `models/model.pkl`

### 5. Launch the app
```bash
streamlit run app.py
```
The app opens at `http://localhost:8501`.

## ☁️ Streamlit Community Cloud Deployment

1. Push the repository to GitHub (include `data/dataset.csv` and `models/model.pkl`).
2. Go to [share.streamlit.io](https://share.streamlit.io) → **New app**.
3. Select your repo, branch (`main`), and set the main file to `app.py`.
4. Click **Deploy** — Streamlit Cloud installs `requirements.txt` automatically.

> **Note:** Make sure `models/model.pkl` is committed to the repo, or add a post-deploy step that runs `python train_model.py` before starting the app.

## 🧠 ML Details

| Item | Value |
|---|---|
| Problem type | Binary classification (fraud / legitimate) |
| Target column | `is_fraud` |
| Dataset size | 20,000 rows × 25 features |
| Fraud rate | ~1.7 % |
| Models compared | Logistic Regression, Random Forest, Gradient Boosting |
| Selection metric | Cross-validated ROC-AUC (5-fold) |
| Preprocessing | StandardScaler (numeric + bool), OrdinalEncoder (categorical) |

---

## 🛡️ Features Used

**Numerical:** `amount_usd`, `hours_since_last_txn`, `txn_count_last_24h`, `distance_from_home_km`, `card_age_months`, `customer_age`, `account_balance_usd`, `cvv_retry_count`, `velocity_score`, `time_of_day_hour`, `day_of_week`, `merchant_risk_score`, `prior_disputes`

**Categorical:** `merchant_category`, `card_type`, `auth_method`, `channel`, `device_type`

**Boolean flags:** `is_foreign_transaction`, `is_new_merchant`, `used_vpn`, `ip_country_mismatch`, `billing_shipping_mismatch`, `is_ai_generated_scam_attempt`
